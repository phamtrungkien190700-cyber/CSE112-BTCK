# Thông tin đề tài

- [x] **Tên đề tài:** Legal Path - Điều hướng thông tin pháp lý.
- [x] **Tên trang đã thực hiện:** Tìm kiếm chuyên gia pháp lý (giao diện người dùng).
- [x] **Mục đích của trang:** Giúp người dùng tìm kiếm, xem thông tin chuyên gia pháp lý và kết nối với chuyên gia để nhận tư vấn, hỗ trợ.
- [x] **Các chức năng chính:**
  - Tìm kiếm chuyên gia theo tên, chức danh hoặc thông tin tư vấn.
  - Hiển thị danh sách và thông tin chuyên gia như tên, chức danh, mô tả và ảnh đại diện dạng chữ viết tắt.
  - Hiển thị nút gửi yêu cầu tư vấn/hỗ trợ trên thẻ chuyên gia.
  - Thông báo trạng thái tải dữ liệu, số lượng kết quả, trường hợp không tìm thấy kết quả hoặc có lỗi tải dữ liệu.
  - Bố cục responsive cho máy tính, máy tính bảng và điện thoại.
- [x] **Công nghệ sử dụng:**
  - HTML5 để xây dựng cấu trúc trang.
  - CSS3 để thiết kế giao diện và responsive.
  - JavaScript để tải dữ liệu từ API và tìm kiếm/lọc danh sách chuyên gia.
  - JSON Server để cung cấp dữ liệu chuyên gia qua REST API.
